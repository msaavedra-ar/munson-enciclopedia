# Munson — Gran enciclopedia del archipiélago

Libro de arte y enciclopedia de un mundo de fantasía, con navegación horizontal animada, índice con búsqueda y vista de impresión.

## Ver online

https://msaavedra-ar.github.io/munson-enciclopedia/

## Archivos

- `index.html`: página completa, con estilos, navegación, contenido e imágenes integradas. Se puede abrir sin conexión y no requiere instalar dependencias.
- `.nojekyll`: permite servir el sitio directamente en GitHub Pages.

## Publicación

GitHub Pages publica desde la raíz de la rama `main`. Para actualizar el sitio, reemplazá `index.html` y guardá el cambio en esa rama.

El contenido y las ilustraciones pertenecen a sus respectivos autores. Este repositorio no concede una licencia de reutilización.
